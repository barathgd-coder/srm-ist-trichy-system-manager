# 🏫 Smart Floor Manager

> **Smart campus navigation and classroom availability platform**

Smart Floor Manager is an intelligent campus platform designed to help students and staff quickly find **available classrooms, labs, and campus spaces**. It combines **AI-powered room search, timetable-based availability, interactive 3D floor maps, live countdowns, and squad coordination** into one unified application.

## ✨ Features

* 🔎 **Smart Search** – Quickly search for classrooms, labs, and facilities.
* 🤖 **AI Room Finder** – Find suitable rooms based on user requirements.
* 🗺️ **Interactive 3D Map** – Explore buildings and floors using an immersive 3D interface.
* 📅 **Timetable-Based Availability** – Check room availability according to the campus timetable.
* ⏱️ **Live Countdown** – See when a room becomes available or occupied.
* 👥 **Call the Squad** – Quickly coordinate with friends or classmates.
* 🏢 **Floor Navigation** – Switch between buildings and floors easily.
* 📱 **Responsive Design** – Optimized for desktop, tablet, and mobile devices.

## 🎯 Problem

Students often waste time searching for classrooms, laboratories, and available spaces across large campuses. Timetable changes and unclear room availability can make navigation even more difficult.

**Smart Floor Manager** solves this problem by providing a centralized platform for discovering and navigating campus spaces.

## 💡 Solution

The platform combines campus timetables with an interactive digital map to provide:

```text
Search Room
     ↓
AI Room Finder
     ↓
Check Timetable
     ↓
View Availability
     ↓
Navigate Using 3D Map
     ↓
Reach the Room
```

## 🧩 Core Modules

### 🔍 Smart Search

Search for rooms, labs, departments, or facilities using simple keywords.

### 🤖 AI Room Finder

The AI-assisted search helps identify rooms based on requirements such as:

* Room type
* Capacity
* Floor
* Availability
* Current timetable

### 🗺️ 3D Campus Map

Explore the campus through an interactive 3D visualization with:

* Buildings
* Floors
* Rooms
* Room status
* Navigation information

### 📅 Timetable Integration

The default campus timetable is used to determine whether rooms are:

* 🟢 Available
* 🔴 Occupied
* 🟡 Starting Soon
* 🔵 Reserved

### ⏱️ Live Countdown

Users can see real-time countdowns such as:

```text
Room 204
Currently Occupied

Available in
00:18:42
```

### 👥 Call the Squad

Users can quickly share room information with their friends or teammates to coordinate meetings and classes.

## 🚀 Getting Started

### 1. Clone the Repository

```bash

```

### 2. Navigate to the Project

```bash
cd smart-floor-manager
```

### 3. Install Dependencies

```bash
npm install
```

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
